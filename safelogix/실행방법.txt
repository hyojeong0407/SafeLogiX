SafeLogiX 실행 방법
===================

1. Docker Desktop 설치 및 실행
   - https://www.docker.com/products/docker-desktop 접속해서 설치
   - 설치 후 Docker Desktop 실행 (트레이에 고래 아이콘 뜨면 준비 완료)

2. .env 파일 생성
   - 프로젝트 루트에 .env.example 파일을 복사해서 .env 로 이름 변경
   - 값 채워넣기 (따로 전달 예정)

3. 프로젝트 루트(safelogix/)에서 터미널 열고 cd src/frontend 친 후 아래 명령어 실행

   처음 실행할 때
   > docker compose up --build

   두 번째부터
   > docker compose up

4. 브라우저에서 http://localhost:5176 접속

5. 종료할 때
   > docker compose down

---
frontend 파일에 docker compose up --build 한 후에 node_modules이 생길건데
cd src/frontend
npm install

한 후에 docker compose up 이거 할 것!!
